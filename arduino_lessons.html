About Arduino

Arduino is a small electronic board with a brain called a microcontroller. It helps beginners and young makers control lights, sounds, motors, and sensors by writing simple programs. With Arduino, you can turn ideas into real projects, like blinking LEDs, moving robots, and interactive tools.

Arduino Uno Parts

USB Port

The USB port connects the board to your computer so you can send code and power the Arduino.

Digital Pins

Digital pins let the Arduino read switches or turn lights and motors on and off.

Analog Pins

Analog pins read changing values from sensors like light or temperature sensors.

Power Pins

Power pins give energy to your board and connected components like LEDs and sensors.

Reset Button

Press the reset button to restart the code without unplugging the board.

Components Needed

Arduino Uno

The main board that runs your code and connects to sensors and lights.

Breadboard

A board for building circuits without soldering, so parts can be moved easily.

LED

A small light that turns on when the Arduino sends power through it.

Resistor

A tiny component that protects the LED by controlling the current.

USB Cable

Connects the Arduino to your computer to upload code and power the board.

First Code Example

void setup() {
  pinMode(13, OUTPUT); // Set digital pin 13 as an output
}

void loop() {
  digitalWrite(13, HIGH); // Turn the LED on
  delay(1000);            // Wait 1 second
  digitalWrite(13, LOW);  // Turn the LED off
  delay(1000);            // Wait 1 second
}

Challenge

Beginner challenge: Can you change the blinking speed? Try making the LED blink faster or slower by editing the delay times in the code above.
